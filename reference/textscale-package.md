# textscale: Measure Latent Quantities from Documents Using Pairwise Comparisons

Implements a method for measuring latent quantities (e.g., ideology, ad
tone, argument persuasiveness) from documents by combining embeddings
with pairwise comparisons. Pairwise annotations — generated by human
annotators or a large language model — identify a latent dimension in
embedding space. An L2-regularized logistic regression model is then fit
on embedding differences, enabling efficient scoring of new documents
without additional pairwise annotations.
